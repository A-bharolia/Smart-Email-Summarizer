# Smart Email Summarizer

An AI-powered application that summarizes emails and extracts important information such as key points, action items, deadlines, priority, and sentiment.

## Project Objective

The goal of this project is to reduce the time users spend reading long emails by using Generative AI to analyze and summarize email content.

## Planned Features

- AI-powered email summarization
- Key point extraction
- Action item detection
- Deadline extraction
- Email priority classification
- Sentiment analysis
- TXT and EML file support
- Email analysis history
- Interactive Streamlit dashboard

## Technologies

- Python
- Generative AI
- Streamlit
- SQLite
- Pandas
- Git/GitHub

## Project Status

Day 1 - Project setup and initial Streamlit interface completed.

## Database

The application uses SQLite to store analyzed emails and their AI-generated insights.

Stored information includes:

- Email subject
- Sender
- Email content
- Summary
- Key points
- Action items
- Deadlines
- Priority
- Sentiment
- Analysis timestamp

## Email History

Users can:

- View previously analyzed emails
- Search emails
- Filter emails by priority
- Review previous AI analysis
